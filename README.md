# DESIGN DIRECTION

Create a visually impressive, premium portfolio with:

* Clean modern typography
* Large editorial-style headings
* Generous whitespace
* Sophisticated dark/neutral color palette
* Subtle gradients
* Minimal glassmorphism where appropriate
* Smooth scroll animations
* Micro-interactions
* Hover animations
* Elegant page transitions
* Subtle motion, NOT excessive animations
* Excellent mobile responsiveness

Preferred visual direction:

**Apple × Linear × Vercel × modern startup portfolio**

Avoid:

* Generic blue AI templates
* Excessive neon
* Robot/brain AI graphics
* Stock photos
* Overly colorful cards
* Excessive rounded rectangles
* Corporate-looking resume layouts
* Fake statistics
* Fake projects or achievements

Use abstract visual elements, typography, subtle grids, gradients and motion instead of stock photography.
